# DevFolio

> This project was an assignment (task) from the Front-End Development diploma I studied at **Route Academy**. It's kept here only to document my learning, not as a production app.

**Live demo:** https://mr-farhat.github.io/Devfolio/

A one-page portfolio template with about, skills, services, work, blog and contact sections.

## What I practiced

- Building a multi-section page with the Bootstrap 5 grid
- Navbar with scrollspy and a dropdown
- A back-to-top button that shows up after scrolling

**Built with:** HTML, CSS, JavaScript, Bootstrap 5, Font Awesome
